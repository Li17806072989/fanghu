# MVP 页面清单

## 前台门户

| 路由 | 页面 | 核心能力 |
|---|---|---|
| `/` | 首页 | 搜索、广告位、专题入口、热点资讯、对接成果 |
| `/topics` | 专题中心 | 分类筛选、关键词搜索、分页 |
| `/topics/:id` | 专题详情 | 条目汇总、相关方案、推荐资讯、联系入口 |
| `/solutions` | 解决方案库 | 装备分类、场景标签、供应商筛选 |
| `/solutions/:id` | 方案详情 | 企业信息、摘要、授权下载/咨询 |
| `/articles` | 军事资讯 | 分类、热点排行、来源和时间 |
| `/articles/:id` | 资讯详情 | 正文、来源、相关推荐 |
| `/supplier/apply` | 供应商入驻 | 企业资料、资质附件、审核状态 |
| `/supplier/:id` | 企业主页 | 企业介绍、方案列表、联系申请 |
| `/customer/demands` | 客户需求 | 提交需求、查看线索进度 |
| `/login` | 登录注册 | 客户/供应商账号入口 |

## 供应商工作台

- `/workbench`：曝光、浏览、咨询、下载、有效线索指标。
- `/workbench/solutions`：方案新增、编辑、分类、提交审核、版本管理。
- `/workbench/leads`：查看线索、更新跟进状态。
- `/workbench/company`：企业资料与认证状态。

## 运营后台（沿用 RuoYi 权限框架）

- 专题分类/专题条目管理。
- 资讯分类/资讯审核发布。
- 供应商入驻和资质审核。
- 方案审核、下架、文件安全扫描结果。
- 客户需求与线索分配。
- 广告位与首页推荐。
- 对接效果和供应商反馈报表。
- AI 任务、下载权限和审计日志。
